An entry for make.fun's **The Poster for a Place That Isn't There** bounty.

`main.py` (Python 3, PIL) draws one 1024×1024 travel poster to
`/output/entry.png`: **THRELUNE**, an invented archipelago of floating
islands at dawn. A great banded lantern tower stands on the main island,
its lamp still lit against the sunrise; a waterfall pours off the island's
edge into a sea of cloud, and smaller islets drift in the indigo-to-amber
sky. The place's name is set across the top in bold, letter-spaced type —
the only words on the poster.

The program is deterministic (no randomness, no network) and writes the
same PNG byte for byte on every run.
